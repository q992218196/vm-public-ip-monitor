## 明确的能力边界

1. 公网 IP 是资产标识，节点是观察点。重复 CIDR 不代表归属；不能仅凭观测断定唯一宿主机。
2. 不读取 VM 内配置、进程、文件或认证日志；不支持宿主机侧还原 VM 内攻击进程。
3. HTTP／TLS 识别支持有界、顺序的 TCP 片段；乱序、缺口、IP 分片、跨 TLS 记录 ClientHello 可能无法识别，并尽可能记录解析缺口。
4. 不解密 TLS/ECH；TLS 证书、网页内容通过主动访问获得，当前不做被动 TLS 1.3 证书还原。
5. 首版不实现 QUIC/HTTP3 域名解析、VXLAN/GRE 解封装或 eBPF 采集；必须配置能够看到公网 IP 层的 Ethernet 采集点。
6. 扫描基于可解释阈值。缺少实际认证结果的连接只能称疑似爆破；不承诺精确跨小时慢速扫描或自适应基线。
7. 内容分类为关键词提示，不是大模型图像分类，也不做违法性质自动判定。首页不能代表整站；人工分类优先。
8. 主动发现按受限任务执行，不提供无人值守的全 IPv4/IPv6 大范围全端口扫描；没有访问、域名线索或具体IPv6地址时不能保证发现全部站点。
9. 截图默认不接受无效 HTTPS 证书，阻止第三方资源与跨站跳转，失败原因保留在任务中。
10. 内存和磁盘限额优先保护宿主机；达到限额时牺牲采集完整性并报告，不承诺无限吞吐或断网无限保存。

## 生产验收清单

- OVS 与 bridge 各选一台试点，确认公网 IPv4／IPv6 请求与响应都可见。
- 访问测试站点的80、443及自定义高端口，检查域名、IP、端口、协议和截图。
- 两个节点填同一 CIDR，核对一个 IP 的两个观察点独立保存。
- 使用授权测试目标生成连接行为，确认扫描告警和正常业务白名单。
- 断开管理端10分钟再恢复，核对幂等补传；缩小缓存验证淘汰与丢弃指标。
- 压测新连接速率和包速率，记录进程内存、cgroup内存、宿主机增量、CPU、内核丢包与状态淘汰。
- 停止 Redis／队列进程后恢复，确认 inbox 接收限额、恢复处理和重复任务幂等。
- 验证截图容器 IPv6 出口、浏览器沙箱、超时、磁盘配额及内网阻断。
- 演练管理员、只读账号、节点禁用、凭据轮换、备份恢复和 Agent 回滚。

未通过上述检查前，建议保持仅告警模式；本版本本身不执行封禁或隔离。
